# For Advertisers

This section covers documentation for advertisers on the features you can use
on the Falcon ads network.

## Features

### [Suppression Lists](/advertisers/suppression-lists/overview)

Send Falcon a hashed list of your existing customers so your campaigns stop
being shown to them.
